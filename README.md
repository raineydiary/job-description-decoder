# 秋招 JD 黑话翻译器

把招聘 JD 里的漂亮话、职场黑话和隐藏要求，翻译成求职者真正看得懂的人话。

## 这是什么

这是一个为秋招求职者设计的轻量互动小游戏。粘贴一段招聘 JD，工具会识别其中有代表性的“漂亮话”，并用更直接、幽默的表达告诉你：招聘方可能真正想说什么。

- 正式名称：秋招 JD 黑话翻译器
- 视觉方向：Y2K × 像素 BB 机
- 运行方式：纯前端，本地解析，不上传用户输入
- 小红书版本：v1.0.0
